06 · Team tool · Page audit

Run the decision test on a real page

1

List every element on the page

2

Name the page’s journey stage and its one goal

3

Ask the three questions of each element

4

Keep it, move it to a better stage, or remove it

Example · checkout page

ElementGoal?Effort?Trust?Verdict
Order summaryYesYesYesKeep
Security messageYesNoYesKeep
Coupon fieldYesNoNoKeep, collapsed
Wishlist linkNoNoNoMove to explore
Flash sale bannerNoNoNoRemove
Full site menuNoNoNoRemove
A practical way to run the CAUX decision test in a design review. The three questions are: does it help the current goal, does it reduce cognitive effort, does it build trust at this stage. The paper’s rule is that an element meeting none of them should have its visibility reconsidered. The example verdicts are illustrative; run the exercise on your own pages.
