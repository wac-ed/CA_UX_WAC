08 · Page-level priorities

What each key page should lead with

Homepage

✓ Clear value proposition

✓ Prominent search

✓ Primary categories

✓ A few featured collections

✓ Delivery, returns, secure payment

Product card

✓ Image

✓ Name

✓ Price

✓ Rating

✓ Availability

✓ Delivery estimate

Product detail page

✓ High-quality images

✓ Transparent pricing

✓ Delivery information

✓ Specifications

✓ Reviews and FAQs

✓ Return policy

Homepage: wishlists, loyalty promotions and big campaigns stay valuable but shouldn’t dominate the first impression. Product listing cards: only what initial evaluation needs; delivery estimate where relevant. Product detail page: present practical details in a logical order; storytelling is valuable but must not block the information users need. The goal of the product page is to eliminate uncertainty, not to impress.
